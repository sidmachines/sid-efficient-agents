What the results establish

No memory rule wins everywhere. Recent memory adapts well to changed goals; diverse memory preserves earlier knowledge in the small neural experiment. At the primary 128-transition setting, coverage memory has no clear average advantage over recent memory. A small raw buffer can also use more storage than aggregated transition statistics.

The package reports 2,100 seeded control-agent runs and 140 small neural-classifier runs, rather than thousands of distinct model architectures. All experiments ran locally. LLM use is a proposed application with a validation protocol; no LLM or GPU result is claimed.

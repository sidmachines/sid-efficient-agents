Analysis decisions recorded while the main experiment was still executing and before reading aggregate outcomes

1. Use a paired seed-block bootstrap for the primary aggregate. A seed index is shared between methods and environments; resampling the same seed index across the four stationary tasks preserves this dependence. The task set is fixed. The interval does not quantify uncertainty over all possible tasks. This specifies the protocol's aggregate bootstrap more conservatively.
2. The recursive raw byte counter includes ndarray headers but misses the owning buffer of a reshaped array. The model-based action-value table is one such view. Analysis adds its exact one-dimensional allocation (112 + 8 * states * actions bytes on the measured runtime) after the first planning pass. Raw values remain unchanged in runs.csv; corrected values and the correction itself are explicit in run_metrics.csv. Temporary planning arrays and process RSS remain excluded.
3. The post-change area is calculated only over the measured post-change interval, interactions 1750 through 3000. The evaluation at 1500 is before the goal changes and must not be interpolated into the post-change curve.
4. Primary endpoint and comparison were fixed before execution. All other capacity, environment, and planning comparisons are exploratory; their intervals are not multiplicity-adjusted.
5. A local process-pool permission failure during the smoke run led to serial execution. No main scientific parameter changed. Training runs use bundled Python 3.12 and NumPy 2.3.5; analysis/figures use locally available Python and Matplotlib, with versions recorded separately. No external API or GPU was used.
